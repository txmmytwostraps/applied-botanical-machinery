# Applied Botanical Machinery

mana through ae2, what could go wrong

A Minecraft addon mod for Botania which makes automation easier.

Unofficial NeoForge 1.21.1 port of Applied Botanics, Botanical Machinery and Botanical Machinery Extra Reforked, in one
mod, for Botania Revived.

- Applied Botanics: https://github.com/ramidzkh/Applied-Botanics
- Botanical Machinery: https://github.com/ChaoticTrials/BotanicalMachinery
- Botanical Machinery Extra Reforked (BOLT_M4G1C): https://github.com/BOLTMAGIC/Botanical-Machinery-Extra-Reforked
- Botanical Machinery Extra (LMor): https://github.com/lentel27/ExtraMachinery

## What's different in this port

- One mod with one id, `appliedbotanicalmachinery`, and one creative tab.
- Runs on Botania Revived instead of Botania.
- The Mechanical Mana Infuser and the Extra Machinery mana infusers use Masterful Botany instead of MythicBotany.

Needs NeoForge 21.1.240 or newer, Botania Revived 1.0.3, Applied Energistics 2 19.2.18 and LibX 1.21.1-6.0.15. Masterful
Botany and JEI are optional.

Report issues with this port here, not to the original authors.
